# Security Policy

Supported version: the latest commit on the default branch.

Report vulnerabilities privately to the repository owner (do not open public
issues): description, reproduction steps, commit hash. Expect acknowledgement
within 7 days.

Notes: this service stores no reporter identities by design. Do not commit
moderator keys, `.env` files, or database files. Rotate `MODERATOR_API_KEY`
if ever exposed.
